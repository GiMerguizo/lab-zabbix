# Instalação no Debian 12

## Criando a VM para rodar o Zabbix
Plataforma: AWS

1. Criar uma instância EC2
<br>
Configurações:
- SO: Debian 12
- Arquitetura: 64 bits (x86)
- Tipo de instância: t2.micro
- Permitir o tráfego HTTP/HTTPS
- O resto deixar _default_

2. Conectar na instância para configurar
